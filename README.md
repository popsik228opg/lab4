Бубнов А пи2-1 lab4 Лабораторная работа №4 — ООП в Java
Описание проекта

Программа рассчитывает доход таксопарка за рабочую неделю (5 дней). В таксопарке работают 16 машин: эконом- и бизнес-класса.

Основное задание — рассчитать доход таксопарка за неделю.

Дополнительное задание — каждый день увольнять таксиста с наименьшим доходом и рассчитывать доход таксопарка с учётом увольнений.

Описание файлов
carsclass

Содержит абстрактный класс Car. В нём хранятся стоимость одного часа поездки и количество отработанных часов. Также класс содержит методы для расчёта дохода и изменения рабочего времени.

busnescar

Содержит класс BusinessCar, который наследуется от Car. В нём задаётся случайная стоимость часа поездки для бизнес-класса в диапазоне от 450 до 600 рублей.

economcars

Содержит класс EconomCar, который наследуется от Car. В нём задаётся случайная стоимость часа поездки для эконом-класса в диапазоне от 150 до 300 рублей.

main

Содержит главный класс Main, который запускает программу и вызывает методы расчёта дохода таксопарка для основного и дополнительного заданий.

realiz-main-add

Содержит класс TaxiService. Он создаёт машины таксопарка, рассчитывает ежедневный и общий доход за пять рабочих дней. В дополнительном задании программа находит таксиста с наименьшим доходом, увольняет его в конце каждого дня и выводит количество оставшихся таксистов.

Запуск программы

Для запуска необходимо открыть проект в IntelliJ IDEA или другой среде разработки Java и запустить класс Main.

Результаты расчётов выводятся в консоль.

Результат

В результате выполнения программы выводится доход таксопарка за каждый день и за всю рабочую неделю для основного и дополнительного заданий.
